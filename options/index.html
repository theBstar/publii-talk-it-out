Dictate posts, draft whole articles by talking, and edit in place with your voice.

Starting…

Start writing

Opens a new post and starts listening in Draft mode. Talk through your article, then say finish the draft.

Inside any post or page editor there's a floating mic panel. Shortcuts: ⌥⇧V listen, ⌥⇧C dictate / edit, ⌥⇧D draft.

Speech recognition

Listening

Claude optional

Turns a rambling dictation into a structured article in your own words, and handles free-form edits such as Claude, tighten this paragraph or Claude, add a conclusion. Without it, drafts are inserted as dictated and only the built-in commands work.

Voice commands

Any time

  • new paragraph new line
  • scratch that undo redo
  • stop listening help

After the wake word, or in Edit mode

  • replace teh with the delete basically
  • select the last sentence select paragraph
  • bold that italicize the quick fox
  • make this a heading turn this into a numbered list
  • heading two: Why it matters
  • delete the last sentence delete this paragraph
  • go to the end next paragraph
  • set the title to … read this back save

Drafting

  • start a draft heading: …
  • finish the draft cancel draft

Privacy

            
    
                
  • With on-device recognition, audio is processed in Publii and never uploaded.
    • 
                
  • With a cloud API or Claude, the audio clip or the post text is sent to that provider when you speak or edit.
    • 
                
  • Keys are stored in Publii's local app storage on this computer, not in your site files or backups.
